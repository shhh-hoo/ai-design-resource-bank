# AI Design Resource Bank

A reusable design-resource bank optimized for AI-assisted production rather than passive bookmarking.

The repository stores **resource packages**: each package preserves provenance, explains the reusable design mechanism, and includes the most useful machine-consumable representations (for example prompts, skills, code, SVG, PNG, tokens, motion specs, or structured notes).

The ingestion workflow and package schema are being bootstrapped in a review branch.
